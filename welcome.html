🎯 What does Save2Project do?

Save2Project helps you save the current webpage as a small, portable HTML shortcut file inside your local project directory.

The saved .html file keeps a link to the original webpage. Double-click it later and it will open in your system's default browser and redirect you back to the original page.

🌍 Cross-platform: HTML shortcut files can be used on macOS, Windows, and Linux, making them easy to keep together with your project files.

🚀 How to get started

📌 Pin the extension for easy access:
Click the Extensions button (🧩) in the Chrome toolbar
Find Save2Project in the extension list
Click the pin icon next to Save2Project
Navigate to any webpage you want to save
Click the Save2Project extension icon
Choose the project directory where you want to save the .html file
Double-click the saved HTML file anytime to reopen the original webpage

💡 Tips

  • Files are automatically named using the webpage title
  • Spaces and Unicode characters, including Chinese characters, are preserved whenever possible
  • Characters that are unsafe in filenames are automatically replaced
  • Saved HTML shortcuts are lightweight and easy to keep under version control with Git
  • You can copy your project between macOS, Windows, and Linux without relying on platform-specific shortcut formats
  • Great for organizing research papers, documentation, datasets, references, tutorials, and other online resources
